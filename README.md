# interview-analyze-skills

给求职候选人使用的面试准备 Skills。围绕一家目标公司和一个岗位，了解业务和工作职责，再练习如何回答面试官的问题。

## 选择 Skill

| Skill | 适用场景 | 输出 |
| --- | --- | --- |
| [interview-prep](interview-prep/SKILL.md) | 想知道这家公司在做什么，这个岗位要解决什么问题 | 中文面试简报，涵盖行业、公司、核心产品、用户画像、团队和岗位分析，并提供求职动机、职业规划和面试反问 |
| [interview-questions](interview-questions/SKILL.md) | 想练习目标岗位可能问到的问题 | 按岗位贴合度排序的 Markdown 题单。每题附考察点、入选依据和口述参考回答，有追问时也提供对应的回答 |

## 快速开始

在能够读取本地文件的 AI 助手中打开仓库目录，提供目标公司和岗位描述（JD）。简历或项目经历用于个性化回答，产品资料、面经和已知面试轮次可以帮助筛选更贴合的题目。

**生成面试简报**

```text
请读取 interview-prep/SKILL.md，结合我给出的公司、岗位 JD 和简历，
生成一份面试简报，帮我准备岗位理解、求职动机、职业规划和面试反问。
```

**生成面试题单与参考回答**

```text
请读取 interview-questions/SKILL.md，根据我提供的岗位 JD、产品资料和面经，
生成一份面试题单。请为每道主问题和加入的追问提供口述参考回答，并将题单保存为 Markdown 文件。
```

两个 Skill 可以单独运行，也可以把 `interview-prep` 的简报作为生成题单时的补充材料。题单的默认文件名为 `公司-岗位-面试问题.md`，可以在请求中指定保存位置。

## 题目和回答的依据

题量由岗位相关度决定。引用面经时保留来源及适用的岗位、轮次或时间。缺少同岗面经时，可以根据 JD 职责和产品场景推演，并在题目下写明依据。经历类参考回答使用候选人提供的真实经历，关键信息不足时保留待填项。
